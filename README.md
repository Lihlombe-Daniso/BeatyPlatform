## Beauty Connect :  Beauty Services Mobile Application

Beauty Connect is a mobile application project designed to connect users with beauty professionals and make discovering beauty services more convenient. The platform aims to simplify the process of finding suitable service providers through an intuitive, user-friendly interface.

The application is being developed using React Native, TypeScript, Expo, and Supabase, with a focus on modern mobile app design, user authentication, and a smooth user experience.

## Key Features

## User Authentication:
Registration, login, and password-reset functionality.
## Beauty Service Discovery: 
An interface designed to help users explore beauty professionals and available services.
## Search and Filtering: 
A planned approach to finding suitable providers based on relevant criteria.
## Booking Experience: 
A design for making beauty service appointments more convenient.
## User-Friendly Interface:
Application screens developed from wireframes with an emphasis on usability and consistent design.
Technologies Used

## React Native , TypeScript , Expo , Supabase , Visual Studio Code

## Project Objective

The objective of Beauty Connect is to create an accessible digital platform that bridges the gap between customers and beauty professionals while providing practical experience in mobile application development, UI implementation, backend integration, and software debugging.

## Project Status:
In development.
